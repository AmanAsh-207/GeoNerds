# 🌍 GeoNerds

An interactive geography based game built using Godot.
Made for the nerds who know about "The World Map"

## 🎮 Features
- Get to know about "The Map"
- Difficulty levels (Easy / Hard)
- Sound system with music manager
- Interactive UI (zoom, drag, buttons)

## 🛠️ Tech Stack
- Engine: Godot
- Language: GDScript
- Assets: Custom + Open Source

## 🚀 How to Run
Open `geo-nerds-the-game.vercel.app` on any browser.

or

1. Clone the repo
2. Open in Godot
3. Run `main_menu.tscn`

or 

Open `https://amanash207.itch.io/geonerds` on any browser
